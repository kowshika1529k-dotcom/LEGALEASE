# LEGALEASE
AI POWERED LEGAL DOCUMENT GENERATOR
## AI Model Selection

LegalEase uses Google Gemini as the AI model for generating legal documents.

### Reason for selection

- Understands user requirements
- Generates structured text
- Can be integrated with Python
- Supports API-based integration


## Project Architecture

Frontend: Streamlit
Backend: FastAPI
AI Model: Google Gemini API

User → Streamlit → FastAPI → Gemini API → Legal Document
